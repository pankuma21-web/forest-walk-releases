# Forest Walk

森で会話を楽しむオンラインゲーム。テストプレイのダウンロードページです。

## ダウンロード

| お使いのパソコン | ダウンロード |
| --- | --- |
| Windows | [Windows版をダウンロード](https://github.com/pankuma21-web/forest-walk-releases/releases/latest/download/ForestWalk-Windows.zip) |
| Mac（Apple Silicon / Intel） | [Mac試作版をダウンロード](https://github.com/pankuma21-web/forest-walk-releases/releases/download/v3/ForestWalk-Mac.zip) |

### 遊び方

1. お使いのパソコンに対応するZIPをダウンロードし、展開してください。
2. Windowsは「Forest Walk.exe」、Macは「Forest Walk.app」を開いてください。
3. 「更新して遊ぶ」を押すとゲームデータを取得します。テスト開催中に入室できます。

次回のテストも同じアプリから参加できます。ゲームの更新はアプリ内で行えます。Windows・Macともに同じゲームサーバーへ接続します。同時入室は3人までです。

### Mac試作版について

Mac実機での動作確認と、Appleの正式署名・公証は未完了です。macOSの保護機能により起動がブロックされる場合があります。Mac版は試作版としての配布です。展開したフォルダー内の「はじめに.txt」もご確認ください。

ゲームデータはアプリ内で更新できます。Macアプリ自体の更新が必要な場合は、このページから再ダウンロードしてください。
