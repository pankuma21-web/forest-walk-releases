# Forest Walk

森を歩いて、集まって、話そう。

お使いのパソコンを選んで、無料でダウンロードできます。

[![Windows版をMicrosoft Storeで入手](https://github.com/pankuma21-web/forest-walk-releases/raw/refs/heads/main/download/windows.svg)](https://apps.microsoft.com/detail/9P8RSHWM8KD7)

Microsoft Storeからインストールして、スタートメニューの「Forest Walk」を開いてください。更新もStoreから行います。

[![Mac版ZIPをダウンロード](https://github.com/pankuma21-web/forest-walk-releases/raw/refs/heads/main/download/mac.svg)](https://github.com/pankuma21-web/forest-walk-releases/releases/download/v3/ForestWalk-Mac-zipfix.zip)

ZIPを展開してアプリを開き、「更新して遊ぶ」を押してください。

## 遊べる時間

| 遊び方 | Windows（Store版） | Mac（現在のZIP版） |
| --- | --- | --- |
| ひとりで散策 | いつでも遊べます | 現在は未対応です |
| オンライン | テスト開催中に参加できます | テスト開催中に参加できます |

オンラインは最大5人で遊べます。開催時間はXなどの告知をご確認ください。開催時間外はオンラインに参加できません。

一般プレイヤーはGoogleログインなしで参加できます。

<details>
<summary>Macで初めて起動するとき</summary>

Mac版は試作版です。Appleの正式署名・公証とMac実機でのゲーム動作確認は未完了です。

起動時にAppleの確認警告が出た場合は、システム設定 → プライバシーとセキュリティ →「このまま開く」で、このアプリの起動を許可できます。

</details>
